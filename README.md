# Cronograma de estudos · Insper

Plano de 12 semanas para o vestibular do Insper, com teoria e questões reais
de provas anteriores organizadas dia a dia.

## O que tem aqui

| Pasta | Conteúdo |
| --- | --- |
| [`plano-estudos/`](plano-estudos) | Site do cronograma (Next.js). É onde fica o plano, a teoria e as questões. |
| [`provas_antigas/`](provas_antigas) | PDFs das provas objetivas do Insper usadas como fonte das questões. |

## Como o plano é organizado

- **3 fases:** Fundamentos (semanas 1–4), Aprofundamento (5–8) e Reta final (9–12).
- **Cada dia com um foco:** Matemática na segunda, quarta e sexta; as outras
  matérias na terça e na quinta; simulado no sábado; redação no domingo.
- **Questões reais:** mais de 200 questões transcritas das provas do Insper e
  de provas da UNESP (mesma banca, Vunesp), ligadas ao tópico do dia. Não há
  gabarito de propósito. O botão *Tirar dúvida com o Claude* copia o
  enunciado pronto para colar numa conversa.
- **Progresso salvo no navegador:** dias concluídos e questões feitas ficam no
  `localStorage`, sem login.

## Rodando localment

```bash
cd plano-estudos
npm install
npm run dev
```

Abre em [http://localhost:3000](http://localhost:3000). Mais detalhes em
[`plano-estudos/README.md`](plano-estudos/README.md).
